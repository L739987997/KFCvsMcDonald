# MIDNIGHT TAKEOUT

## [點這裡直接玩 / Play online](https://l739987997.github.io/KFCvsMcDonald/)

手機請橫屏：左下搖桿移動，推到底跑步；右下 PUNCH 出拳、KICK 腳踢、JUMP 跳躍。

電腦：WASD／方向鍵移動，連按方向跑步；J 出拳、K 腳踢、Space 跳躍。保留手柄操作。

無需下載或解壓縮。首次載入會下載完整遊戲資源，請稍候。存檔保存在各自的瀏覽器。
